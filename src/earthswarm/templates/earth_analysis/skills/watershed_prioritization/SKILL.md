# Watershed Prioritization Skill

Use this when diagnosing watershed degradation, runoff, erosion, recharge, or intervention placement.

Checklist:

- Delineate watershed/sub-watersheds where available.
- Compare slope, drainage density, land use, soils, rainfall, and erosion indicators.
- Identify process zones: runoff generation, sediment source, conveyance, deposition, recharge.
- Match interventions to process zones and local constraints.
- Flag data gaps and monitoring indicators.

Output: zone, process, evidence, suitable interventions, cautions, map request.
