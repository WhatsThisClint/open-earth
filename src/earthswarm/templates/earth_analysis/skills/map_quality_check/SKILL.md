# Map Quality Check Skill

Use this before accepting any map as report-ready.

Check:

- Purpose: the map answers a specific analytical question.
- Title, legend, scale, north arrow where useful, sources, date.
- CRS/projection and extent are appropriate.
- Symbology is readable and not misleading.
- Labels do not clutter the map.
- Layer order makes sense.
- Map supports the claim it is attached to.

Output: pass/fail, blocking issues, important issues, polish issues, recommended fix.
